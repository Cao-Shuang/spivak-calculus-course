# Spivak · 微积分研习室

网站：https://cao-shuang.github.io/spivak-calculus-course/

基于 Michael Spivak《Calculus》第四版整理的微积分网页课程。

- 30 章中文课程与 Insight，396 个学习单元。
- 30 章英文原文、中文译文及逐段中英对照，覆盖 596 个印刷页位置。
- 824 组习题、分层提示、证明研习、30 个交互实验和学习笔记。
- 数学排版、图示、教材及答案册参考页随站点提供。

本仓库为独立静态发布版本，GitHub Pages 使用 `main` 分支根目录，无需构建。入口为 `index.html`。学习记录存于当前浏览器，可通过课程中的导出与导入功能备份。

原书、答案册及相关插图权利归原著作权人所有；本仓库不为这些内容授予开源许可。
