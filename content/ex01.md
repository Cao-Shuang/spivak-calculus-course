本页按第四版习题 1–25 编排，保留每题的小问。题面改写成中文；解答强调为何允许这样推理。星号沿用原书的挑战提示。请先独立作答，展开提示后仍应自己补写证明。

## 1. 消去律与幂差分解
### 题目

证明：(i) 若 $ax=a$ 且 $a\ne0$，则 $x=1$；(ii) $x^2-y^2=(x-y)(x+y)$；(iii) 若 $x^2=y^2$，则 $x=y$ 或 $x=-y$；(iv) $x^3-y^3=(x-y)(x^2+xy+y^2)$；(v) 对正整数 $n$，$x^n-y^n=(x-y)(x^{n-1}+x^{n-2}y+\cdots+xy^{n-2}+y^{n-1})$；(vi) $x^3+y^3=(x+y)(x^2-xy+y^2)$，并推广到奇数次幂和。
### 提示

前一问建立的结果可用于后一问。一般幂差展开后，中间项会两两抵消。幂和可以把幂差中的 $y$ 换成 $-y$。
### 解答

(i) 两边乘 $a^{-1}$：$(a^{-1}a)x=a^{-1}a$，故 $x=1$。

(ii) 用分配律展开，得到 $x^2+xy-yx-y^2=x^2-y^2$。

(iii) 由 (ii)，$(x-y)(x+y)=0$。域的零乘积性质给出两个因子至少一个为零。

(iv) 展开为 $x^3+x^2y+xy^2-x^2y-xy^2-y^3$，中间抵消。

(v) 用有限和写得更明确：

$$ (x-y)\sum_{k=0}^{n-1}x^{n-1-k}y^k=\sum_{k=0}^{n-1}x^{n-k}y^k-\sum_{k=1}^{n}x^{n-k}y^k=x^n-y^n.$$

(vi) 在 (iv) 中以 $-y$ 代替 $y$。奇数 $n$ 时同理：

$$x^n+y^n=(x+y)\sum_{k=0}^{n-1}(-1)^kx^{n-1-k}y^k.$$

## 2. 找出“2=1”的伪证明
### 题目

令 $x=y$，由 $x^2=xy$ 推出 $x^2-y^2=xy-y^2$，再写成 $(x+y)(x-y)=y(x-y)$，约去 $x-y$ 得 $x+y=y$，于是 $2y=y$，从而 $2=1$。错误在哪里？
### 提示

把每一次“约去”展开成乘以逆元，检查逆元是否存在。
### 解答

$x=y$ 恰好意味着 $x-y=0$，所以关键一步约去了零，没有合法逆元。前面的恒等式实际只给出 $0=0$。最后若再除以 $y$，还须有 $y\ne0$；即使额外设 $y\ne0$，也无法修复中间的除零错误。

## 3. 分数运算的依据
### 题目

证明下列规则并保留非零条件：(i) $a/b=ac/(bc)$，$b,c\ne0$；(ii) $a/b+c/d=(ad+bc)/(bd)$，$b,d\ne0$；(iii) $(ab)^{-1}=a^{-1}b^{-1}$，$a,b\ne0$；(iv) $(a/b)(c/d)=ac/(db)$，$b,d\ne0$；(v) $(a/b)/(c/d)=ad/(bc)$，$b,c,d\ne0$；(vi) $a/b=c/d$ 当且仅当 $ad=bc$，$b,d\ne0$。另问：何时 $a/b=b/a$？
### 提示

分数是乘以逆元的简写。证明某个数是逆元，只需把它与原数相乘，得到 1。
### 解答

(iii) $(ab)(a^{-1}b^{-1})=(aa^{-1})(bb^{-1})=1$，由逆元唯一性得到结论。

(i) $ac(bc)^{-1}=acb^{-1}c^{-1}=ab^{-1}$。

(ii) $ab^{-1}+cd^{-1}=(ad+bc)b^{-1}d^{-1}$，再用 (iii)。

(iv) $ab^{-1}cd^{-1}=ac(bd)^{-1}$。

(v) $cd^{-1}$ 的逆元为 $dc^{-1}$，所以结果为 $ab^{-1}dc^{-1}$。

(vi) 等式两边乘 $bd$ 得 $ad=bc$；反向乘 $(bd)^{-1}$。最后一问首先要求 $a,b\ne0$，然后等价于 $a^2=b^2$，即 $a=b$ 或 $a=-b$。

## 4. 十四个不等式：定义域、根与符号
### 题目

分别求出全部实数解：

| 小问 | 不等式 |
|---|---|
| i | $4-x<3-2x$ |
| ii | $5-x^2<8$ |
| iii | $5-x^2<-2$ |
| iv | $(x-1)(x-3)>0$ |
| v | $x^2-2x+2>0$ |
| vi | $x^2+x+1>2$ |
| vii | $x^2-x+10>16$ |
| viii | $x^2+x+1>0$ |
| ix | $(x-\pi)(x+5)(x-3)>0$ |
| x | $(x-\sqrt[3]2)(x-\sqrt2)>0$ |
| xi | $2^x<8$ |
| xii | $x+3^x<4$ |
| xiii | $1/x+1/(1-x)>0$ |
| xiv | $(x-1)/(x+1)>0$ |
### 提示

先列分母非零条件。多项式按根分区间判断符号；始终为正的二次式用配方。指数函数的严格单调性将在后文从定义建立，此处可用熟悉的初等事实。
### 解答

| 小问 | 全部解及原因 |
|---|---|
| i | $x<-1$，移项即得 |
| ii | 所有实数，因为 $5-x^2\le5<8$ |
| iii | $x<-\sqrt7$ 或 $x>\sqrt7$ |
| iv | $x<1$ 或 $x>3$，两因子同号 |
| v | 所有实数，$(x-1)^2+1>0$ |
| vi | $x<(-1-\sqrt5)/2$ 或 $x>(-1+\sqrt5)/2$ |
| vii | $x<-2$ 或 $x>3$，因为 $x^2-x-6=(x-3)(x+2)$ |
| viii | 所有实数，$(x+1/2)^2+3/4>0$ |
| ix | $-5<x<3$ 或 $x>\pi$；按 $-5<3<\pi$ 排列三个根 |
| x | $x<\sqrt[3]2$ 或 $x>\sqrt2$ |
| xi | $x<3$ |
| xii | $x<1$；左侧严格递增且在 1 处等于 4 |
| xiii | $0<x<1$；通分得 $1/[x(1-x)]$ |
| xiv | $x<-1$ 或 $x>1$；$x=-1$ 无定义，$x=1$ 不满足严格不等式 |

核对：所有严格不等式的等号点都应排除；“乘上分母”前必须先知道分母的符号。

## 5. 十条保序规则
### 题目

证明：(i) $a<b,c<d\Rightarrow a+c<b+d$；(ii) $a<b\Rightarrow-b<-a$；(iii) $a<b,c>d\Rightarrow a-c<b-d$；(iv) $a<b,c>0\Rightarrow ac<bc$；(v) $a<b,c<0\Rightarrow ac>bc$；(vi) $a>1\Rightarrow a^2>a$；(vii) $0<a<1\Rightarrow a^2<a$；(viii) $0\le a<b,0\le c<d\Rightarrow ac<bd$；(ix) $0\le a<b\Rightarrow a^2<b^2$；(x) $a,b\ge0,a^2<b^2\Rightarrow a<b$。
### 提示

把不等式翻译为差属于正数集合。第 (viii) 问不要漏掉 $a=0$ 或 $c=0$。
### 解答

(i) $(b+d)-(a+c)=(b-a)+(d-c)>0$。 (ii) $(-a)-(-b)=b-a>0$。 (iii) 由 (ii) 得 $-c<-d$，再用 (i)。

(iv) $bc-ac=c(b-a)>0$。 (v) 对 $-c>0$ 应用 (iv)，再反向取负。

(vi) 把 $a>1$ 乘正数 $a$。 (vii) 把 $a<1$ 乘正数 $a$。

(viii) 若 $ac=0$，则 $bd>0$。否则 $a,c>0$，连续两次保序得到 $ac<bc<bd$。

(ix) 在 (viii) 取 $c=a,d=b$。 (x) 若 $a=b$，平方相同；若 $a>b$，(ix) 给相反不等式。三歧性仅剩 $a<b$。

## 6. 奇偶次幂与顺序
### 题目

(a) $0\le x<y$ 时，证明所有正整数 $n$ 都满足 $x^n<y^n$。(b) 若 $x<y$ 且 $n$ 为奇数，也有 $x^n<y^n$。(c) 奇数 $n$ 时由 $x^n=y^n$ 推出 $x=y$。(d) 偶数 $n$ 时由 $x^n=y^n$ 推出 $x=y$ 或 $x=-y$。
### 提示

正半轴上用归纳。负半轴上比较 $-y$ 和 $-x$。偶次幂先转成绝对值。
### 解答

(a) $x=0$ 明显。$x>0$ 时，由归纳假设 $x^n<y^n$ 得 $x^{n+1}<yx^n<y^{n+1}$。

(b) 两数非负用 (a)；两数非正时 $0\le-y<-x$，奇次幂保留负号，得到结果；跨零时直接比较符号。

(c) 若 $x\ne y$，三歧性和 (b) 会给出不等的幂，矛盾。

(d) $|x|^n=|y|^n$，由 (a) 的严格单调性得 $|x|=|y|$，所以 $x=\pm y$。

## 7. 两种平均数
### 题目

若 $0<a<b$，证明 $a<\sqrt{ab}<(a+b)/2<b$。并说明 $\sqrt{ab}\le(a+b)/2$ 对所有 $a,b\ge0$ 都成立。
### 提示

分别比较平方；中间一步利用 $(a-b)^2>0$。
### 解答

$a^2<ab$ 且两边非负，故 $a<\sqrt{ab}$。由 $(a-b)^2>0$ 得 $(a+b)^2>4ab$，开方得中间不等式。最后 $a+b<2b$。一般非负情形用 $(\sqrt a-\sqrt b)^2\ge0$ 即得非严格版本，等号当且仅当 $a=b$。

## 8. ★ 从顺序关系重建正数集合
### 题目

假定 P1–P9，并以四条顺序规则替代 P10–P12：三歧性；传递性；平移保序；乘正数保序。定义 $P=\{a:0<a\}$，证明原来的三条正数公理。
### 提示

先从平移保序证明 $a<0$ 当且仅当 $-a>0$。
### 解答

对 $a<0$ 两边加 $-a$ 得 $0<-a$，反向同理。对 $a$ 与 0 使用三歧性，即 $a=0,a\in P,-a\in P$ 恰有一个，得到 P10。

若 $a,b>0$，平移得 $a<a+b$，再由 $0<a$ 和传递性得 $a+b>0$，得到 P11。若 $a,b>0$，对 $0<a$ 乘 $b$ 得 $0<ab$，得到 P12。

## 9. 减少绝对值符号
### 题目

每式至少去掉一对绝对值：(i) $|\sqrt2+\sqrt3-\sqrt5+\sqrt7|$；(ii) $\big||a+b|-|a|-|b|\big|$；(iii) $\big||a+b|+|c|-|a+b+c|\big|$；(iv) $|x^2-2xy+y^2|$；(v) $\big||\sqrt2+\sqrt3|-|\sqrt5-\sqrt7|\big|$。
### 提示

不要一开始就分类。三角不等式能直接告诉你某些内部表达式的符号。
### 解答

(i) 内部为正，结果 $\sqrt2+\sqrt3-\sqrt5+\sqrt7$，因为 $\sqrt7>\sqrt5$。

(ii) 内部非正，结果 $|a|+|b|-|a+b|$。

(iii) 内部非负，结果 $|a+b|+|c|-|a+b+c|$。

(iv) 内部是 $(x-y)^2$，结果 $x^2-2xy+y^2$。

(v) 先得 $|\sqrt2+\sqrt3+\sqrt5-\sqrt7|$。因 $\sqrt2+\sqrt5>\sqrt7$，最终为 $\sqrt2+\sqrt3+\sqrt5-\sqrt7$。

## 10. 完全展开绝对值
### 题目

不保留任何绝对值符号，必要时分情况：(i) $|a+b|-|b|$；(ii) $\big||x|-1\big|$；(iii) $|x|-|x^2|$；(iv) $a-|a-|a||$。
### 提示

在每个内部表达式为零的地方分段。
### 解答

(i) 按 $a+b$ 与 $b$ 的符号：均非负时为 $a$；$a+b\ge0,b<0$ 时为 $a+2b$；$a+b<0,b\ge0$ 时为 $-a-2b$；均负时为 $-a$。

(ii) 当 $x\ge1$ 为 $x-1$；$0\le x<1$ 为 $1-x$；$-1\le x<0$ 为 $1+x$；$x<-1$ 为 $-1-x$。

(iii) $x\ge0$ 时为 $x-x^2$，$x<0$ 时为 $-x-x^2$。

(iv) $a\ge0$ 时内层差为零，结果 $a$；$a<0$ 时 $a-|a|=2a<0$，结果 $a-(-2a)=3a$。

## 11. 距离的方程与不等式
### 题目

求解：(i) $|x-3|=8$；(ii) $|x-3|<8$；(iii) $|x+4|<2$；(iv) $|x-1|+|x-2|>1$；(v) $|x-1|+|x+1|<2$；(vi) $|x-1|+|x+1|<1$；(vii) $|x-1||x+1|=0$；(viii) $|x-1||x+2|=3$。
### 提示

两点之间的距离之和至少是两点距离。最后一问先合并为一个绝对值。
### 解答

(i) $x=-5,11$。(ii) $-5<x<11$。(iii) $-6<x<-2$。

(iv) 在 $[1,2]$ 距离和恰为 1，外部严格大于 1，所以解为 $x<1$ 或 $x>2$。

(v)(vi) 均无解，因为距离和至少为 2。

(vii) $x=\pm1$。

(viii) $|x^2+x-2|=3$，因此 $x^2+x-5=0$ 或 $x^2+x+1=0$。第二式无实根，第一式给 $x=(-1\pm\sqrt{21})/2$。

## 12. 绝对值的七条推论
### 题目

证明：(i) $|xy|=|x||y|$；(ii) $|1/x|=1/|x|$，$x\ne0$；(iii) $|x/y|=|x|/|y|$，$y\ne0$；(iv) $|x-y|\le|x|+|y|$；(v) $|x|-|y|\le|x-y|$；(vi) $\big||x|-|y|\big|\le|x-y|$；(vii) $|x+y+z|\le|x|+|y|+|z|$，并确定等号条件。
### 提示

第 (v) 问写成 $x=(x-y)+y$。第 (vi) 问还需要交换 $x,y$。
### 解答

(i) 按两数正负直接验证；或者两边非负且平方都为 $x^2y^2$。

(ii) 由 (i)，$|x||1/x|=1$，所以 $|1/x|$ 是 $|x|$ 的逆元。(iii) 再用 (i)。

(iv) 对 $x+(-y)$ 用三角不等式。(v) $|x|\le|x-y|+|y|$。(vi) 交换后再得 $|y|-|x|\le|x-y|$，合并两个方向。

(vii) 连用两次三角不等式。等号当且仅当所有非零项同号：设正项之和为 $P$、负项绝对值之和为 $N$，两边分别是 $|P-N|$ 和 $P+N$，相等恰当 $P=0$ 或 $N=0$。

## 13. 用绝对值写最大值和最小值
### 题目

证明 $\max(x,y)=(x+y+|y-x|)/2$，$\min(x,y)=(x+y-|y-x|)/2$。再导出三个数的相应公式。
### 提示

分 $x\le y$ 与 $x\ge y$；三个数使用嵌套。
### 解答

若 $x\le y$，$|y-x|=y-x$，两个式子分别等于 $y,x$；若 $x\ge y$，相反。

令 $M=(y+z+|y-z|)/2$，则 $\max(x,y,z)=(x+M+|x-M|)/2$。完全代入可写为

$$\frac{2x+y+z+|y-z|+|2x-y-z-|y-z||}{4}.$$

令 $m=(y+z-|y-z|)/2$，则最小值为 $(x+m-|x-m|)/2$，即

$$\frac{2x+y+z-|y-z|-|2x-y-z+|y-z||}{4}.$$

## 14. 三角不等式的区间证明
### 题目

(a) 证明 $|a|=|-a|$。(b) 证明 $-b\le a\le b$ 当且仅当 $|a|\le b$，并推出 $-|a|\le a\le|a|$。(c) 由此再证明三角不等式。
### 提示

若 $b<0$，等价关系两边都不可能成立，也应交代。
### 解答

(a) 对非负 $a$ 直接代定义；负数情形对 $-a$ 使用已证情形。

(b) 当 $b\ge0$，分 $a\ge0$ 与 $a<0$ 即得双向蕴含。当 $b<0$，$-b>b$ 使双不等式不可能成立，而 $|a|\ge0>b$ 也排除另一边。取 $b=|a|$ 即得夹逼。

(c) 把 $-|a|\le a\le|a|$ 与 $-|b|\le b\le|b|$ 相加，再用 (b)。

## 15. ★ 两个严格正的多项式
### 题目

若 $x,y$ 不同时为零，证明 $x^2+xy+y^2>0$ 和 $x^4+x^3y+x^2y^2+xy^3+y^4>0$。
### 提示

第一式配方。第二式可利用五次幂严格递增及幂差分解；也可直接配成平方。
### 解答

第一式为 $(x+y/2)^2+3y^2/4$，两项同时为零才可能 $x=y=0$。

第二式为

$$\left(x^2+\frac{xy}{2}\right)^2+\frac34\left(xy+\frac23y^2\right)^2+\frac23y^4.$$

若 $y\ne0$，最后一项严格正；若 $y=0,x\ne0$，第一项严格正。

另一思路：$x\ne y$ 时第二式等于 $(x^5-y^5)/(x-y)>0$；$x=y\ne0$ 时等于 $5x^4>0$。这需要先完成第 6 题。

## 16. ★ 幂何时能分配到和上？
### 题目

(a) 找出 $(x+y)^2=x^2+y^2$ 与 $(x+y)^3=x^3+y^3$ 成立的全部条件。(b) 证明 $4x^2+6xy+4y^2>0$，除非 $x=y=0$。(c) 求 $(x+y)^4=x^4+y^4$ 的全部情形。(d) 求五次幂的全部情形，并猜测一般规律。
### 提示

展开后提取 $xy$；奇数次还会出现 $x+y$ 因子。
### 解答

(a) 二次差为 $2xy$，因此 $x=0$ 或 $y=0$。三次差为 $3xy(x+y)$，多出 $x=-y$。

(b) 写成 $3(x+y)^2+x^2+y^2$，只在二者同为零时为零。

(c) 四次差为 $xy(4x^2+6xy+4y^2)$，由 (b) 得 $x=0$ 或 $y=0$。

(d) 五次差为 $5xy(x+y)(x^2+xy+y^2)$。由第 15 题，只有 $x=0$、$y=0$ 或 $x=-y$。

猜想：对 $n\ge2$，偶数次仅允许一项为零；奇数次还允许互为相反数。这里只证明了 2–5 次，不能把猜想当成一般证明；第 11 章的严格单调性方法将完成推广。

## 17. 配方寻找最小值
### 题目

求最小值与取值位置：(a) $2x^2-3x+4$；(b) $x^2-3x+2y^2+4y+2$；(c) $x^2+4xy+5y^2-4x-6y+7$。
### 提示

多变量也可逐个配方。找到下界还不够，必须说明能够取得。
### 解答

(a) $2(x-3/4)^2+23/8$，最小 $23/8$，$x=3/4$。

(b) $(x-3/2)^2+2(y+1)^2-9/4$，最小 $-9/4$，$(x,y)=(3/2,-1)$。

(c) $(x+2y-2)^2+(y+1)^2+2$，最小 2，$(x,y)=(4,-1)$。

## 18. 判别式、正定性与一般二次式
### 题目

(a) 若 $b^2-4c\ge0$，验证 $(-b\pm\sqrt{b^2-4c})/2$ 满足 $x^2+bx+c=0$。(b) 若判别式负，证明二次式处处正。(c) 用这个事实另证 $x^2+xy+y^2>0$，只排除 $(0,0)$。(d) 哪些 $a$ 使 $x^2+axy+y^2$ 对非零 $(x,y)$ 始终严格正？(e) 求 $x^2+bx+c$ 及 $ax^2+bx+c$（$a>0$）的最小值。
### 提示

二次式配成 $(x+b/2)^2+c-b^2/4$；二元问题先分 $y=0$ 与 $y\ne0$。
### 解答

(a) 方程等价于 $(x+b/2)^2=(b^2-4c)/4$，给出两个根，重根时相同。(b) 平方非负且常数项严格正。

(c) $y\ne0$ 时除以 $y^2$，得到 $t^2+t+1$，其判别式 $-3$；$y=0$ 时结果 $x^2>0$。

(d) $y\ne0$ 时需 $t^2+at+1$ 对所有 $t$ 严格正，即 $a^2-4<0$。故 $|a|<2$。等号边界有非零零点，超出边界会出现负值。

(e) 第一式最小 $c-b^2/4$，在 $x=-b/2$；第二式最小 $c-b^2/(4a)$，在 $x=-b/(2a)$。

## 19. Schwarz 不等式的三种证明
### 题目

证明 $x_1y_1+x_2y_2\le\sqrt{x_1^2+x_2^2}\sqrt{y_1^2+y_2^2}$：(a) 使用关于 $\lambda$ 的二次式 $\sum_{i=1}^2(\lambda y_i-x_i)^2$；(b) 对归一化坐标使用 $2uv\le u^2+v^2$；(c) 使用平方恒等式；(d) 从各证明确定等号条件。
### 提示

先处理零向量。无绝对值版本的等号还要求比例系数非负。
### 解答

记 $A=x_1^2+x_2^2,B=y_1^2+y_2^2,C=x_1y_1+x_2y_2$。

(a) 若 $B>0$，$B\lambda^2-2C\lambda+A\ge0$ 对所有 $\lambda$ 成立，其最小值 $A-C^2/B\ge0$。故 $C^2\le AB$，推出 $C\le\sqrt{AB}$。$B=0$ 时结论立即成立。

(b) $A,B>0$ 时，对 $u_i=x_i/\sqrt A,v_i=y_i/\sqrt B$ 使用 $(u_i-v_i)^2\ge0$ 并求和，得 $2C/\sqrt{AB}\le2$。零向量另行处理。

(c) 展开验证 $AB-C^2=(x_1y_2-x_2y_1)^2\ge0$。

(d) 若 $y=0$，总是等号；否则等号当且仅当 $x=\lambda y$，$\lambda\ge0$。(a) 要求二次式最小值为零且 $C\ge0$；(b) 要求所有归一化坐标相同；(c) 要求行列式为零且 $C\ge0$。$x=0$ 对应 $\lambda=0$。若左侧改为 $|C|$，比例系数就可为任意实数。

## 20. 和与差的误差预算
### 题目

设 $\varepsilon>0$，且 $|x-x_0|<\varepsilon/2$，$|y-y_0|<\varepsilon/2$。证明 $|(x+y)-(x_0+y_0)|<\varepsilon$ 和 $|(x-y)-(x_0-y_0)|<\varepsilon$。
### 提示

把输出差写成两个输入差的和或差。
### 解答

前者不超过 $|x-x_0|+|y-y_0|<\varepsilon$。后者写成 $(x-x_0)-(y-y_0)$，再用同一个三角不等式。这说明误差可以在各项之间分摊。

## 21. ★ 乘积的误差预算
### 题目

证明：若

$$|x-x_0|<\min\left(1,\frac{\varepsilon}{2(|y_0|+1)}\right),\quad |y-y_0|<\frac{\varepsilon}{2(|x_0|+1)},$$

则 $|xy-x_0y_0|<\varepsilon$。
### 提示

拆出 $(x-x_0)y_0+x(y-y_0)$；先控制变化的 $x$。
### 解答

$|x|\le|x-x_0|+|x_0|<1+|x_0|$。因此

$$|xy-x_0y_0|\le|y_0||x-x_0|+|x||y-y_0|<\frac\varepsilon2+\frac\varepsilon2=\varepsilon.$$

即使 $x_0$ 或 $y_0$ 为零也有效，因为选定的分母都加了 1。

## 22. ★ 倒数的误差预算
### 题目

$y_0\ne0$，且 $|y-y_0|<\min(|y_0|/2,\varepsilon|y_0|^2/2)$。证明 $y\ne0$ 且 $|1/y-1/y_0|<\varepsilon$。
### 提示

先保证变化的分母离零有正距离，再通分。
### 解答

反三角不等式给 $|y|\ge|y_0|-|y-y_0|>|y_0|/2>0$。于是

$$\left|\frac1y-\frac1{y_0}\right|=\frac{|y-y_0|}{|y||y_0|}<\frac{2|y-y_0|}{|y_0|^2}<\varepsilon.$$

## 23. ★ 设计商的误差条件
### 题目

固定 $y_0\ne0$ 和 $\varepsilon>0$。给出只依赖 $x_0,y_0,\varepsilon$ 的两个正数界，使 $|y-y_0|$、$|x-x_0|$ 小于这些界时，保证 $y\ne0$ 且 $|x/y-x_0/y_0|<\varepsilon$。
### 提示

可以组合前两题，也可以把商差拆成两项。
### 解答

一个有效选择是

$$|y-y_0|<\min\left(\frac{|y_0|}{2},\frac{\varepsilon|y_0|^2}{4(|x_0|+1)}\right),\qquad |x-x_0|<\frac{\varepsilon|y_0|}{4}.$$

先得 $|y|>|y_0|/2$。再写

$$\frac xy-\frac{x_0}{y_0}=\frac{x-x_0}{y}+x_0\left(\frac1y-\frac1{y_0}\right).$$

第一项绝对值小于 $\varepsilon/2$，第二项小于 $\varepsilon|x_0|/[2(|x_0|+1)]\le\varepsilon/2$，从而结论成立。答案不唯一，关键是界只依赖固定数据且能验证。

## 24. ★ 为什么可以省略任意多个括号？
### 题目

规定 $a_1+\cdots+a_n$ 表示从右向左加括号的和。(a) 证明 $(a_1+\cdots+a_k)+a_{k+1}=a_1+\cdots+a_{k+1}$。(b) 当 $n>k$，证明两个连续分组相加等于整个规定的和。(c) 证明保持原次序、任意合法括号排列所得的和都相同。
### 提示

第一问对项数归纳；最后一问观察最外层加号把表达式分成哪两段。
### 解答

(a) $k=1$ 即定义。假设对 $k-1$ 个数成立，则

$$[a_1+(a_2+\cdots+a_k)]+a_{k+1}=a_1+[(a_2+\cdots+a_k)+a_{k+1}]=a_1+(a_2+\cdots+a_{k+1}).$$

第一步结合律，第二步归纳假设。

(b) 事实上可把后段视为单个元素 $B$。对 $k$ 归纳：$k=1$ 即右嵌套定义；一般情形结合律把 $a_1$ 移出，再对余下 $k-1$ 项使用归纳假设，得到完整右嵌套和。

(c) 对总项数强归纳。任意括号表达式的最外层是前 $j$ 项之和加后 $n-j$ 项之和；两段长度都小于 $n$，先由归纳假设改成规定的形式，再用 (b) 拼接。全程只用结合律，不需要交换律。

## 25. 二元素数系与公理的力量
### 题目

仅用元素 $0,1$，规定 $1+1=0$、$0+0=0$、$0+1=1+0=1$；乘法仍为 $1\cdot1=1$、其他乘积为零。逐条检查 P1–P9，即使这里 $1+1=0$。
### 提示

每条规则只涉及有限个输入，既可枚举，也可把它解释成整数除以 2 后的余数。
### 解答

加法等于奇偶性相加：三个元素的和只取决于其中 1 的个数是否奇数，故结合且交换；0 是单位元，0 的逆元是 0，1 的加法逆元是 1。乘积当且仅当全部因子为 1 才为 1，故结合且交换；1 为单位元，唯一非零元素 1 的乘法逆元为自身。两单位元不同。分配律按外部因子检查：因子为 0 时两侧均零；因子为 1 时两侧相同。

因此前九条全部满足。这是真正的反模型：单凭 P1–P9 不可能证明 $1+1\ne0$。但它不能有兼容的正数结构，因为若为有序域则 $1>0$，从而 $1+1>0$，与 $1+1=0$ 矛盾。
